# 🎓 AI Lecture Agent: 스마트 강의 음성 요약 & 시험 대비 서비스

> **강의 시간표 연동부터 수업 녹음, 핵심 요약, 시험 문제 생성, 타임스탬프 검색 등 가능하게끔**  
> 시중 음성 서비스의 높은 가격 부담을 줄이고, 대학생의 시험 대비 및 복습을 극대화하는 맞춤형 AI 에이전트

---

##   서비스 핵심 시나리오 (User Journey) 예시

* **[시간표 기반 자동 분류]** "이번 학기 시간표 등록할게." → 과목별 녹음 데이터 자동 분리
* **[스마트 수업 정리]** "오늘 수업 3줄 요약 / 교수님 강조 내용만 알려줘" → 키워드, 중요 개념, 교수님 강조 포인트(*) 자동 추출
* **[시험 대비 문제 생성]** "시험 문제 만들어줘" → 객관식/주관식 예상 문제 및 퀴즈 자동 생성
* **[과거 수업 타임스탬프 검색]** "지난주 수업에서 레드블랙트리 설명했던 부분 찾아줘" → 특정 구간(예: 34분 20초) 타임스탬프 및 내용 핀포인트 제공
* **[지능형 복습 알림]** "이번 주 복습해야 할 과목 알려줘" → 주기적 복습 주기에 맞춘 복습 우선순위 추천

---

##   주요 기능 (Key Features)

1. **시간표 & 과목 관리**: 요일/시간별 시간표 등록 및 과목별 수업 노트 자동 정리
2. **수업 음성 녹음 & STT**: 마이크 기반 녹음, OpenAI Whisper 기반 한국어 음성-텍스트 변환
3. **LLM AI 에이전트 엔진**:
   - 3줄 요약 & 교수님 강조 포인트(핵심 키워드) 추출
   - 객관식/주관식 예상 시험 문제 자동 생성
   - 주기적 복습 추천 (Spaced Repetition 알고리즘)
4. **RAG 기반 스마트 강의 검색**: 지난 수업 음성/텍스트 데이터 중 특정 개념 검색 및 타임스탬프 제공

---

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend App**: Flutter (or React Native)
- **Backend Server**: Python FastAPI
- **AI / ML Pipeline**: 
  - **STT**: OpenAI Whisper (`faster-whisper`)
  - **LLM**: GPT-4o-mini / Gemini Flash API
  - **Vector DB / RAG**: ChromaDB / FAISS (강의 내용 검색 및 타임스탬프용)
- **Database**: SQLite / Supabase
